Git y GitHub sin miedo: los comandos del día a día

status, add, commit, push y pull: el flujo básico para guardar tu trabajo y colaborar en equipo sin pisar el código de nadie.

14 de octubre de 2026 ·8 min de lectura

Categoría: Herramientas

¿Alguna vez guardaste archivos como proyecto-final, proyecto-final-v2 y proyecto-final-ahora-si? Git resuelve exactamente ese problema: es un sistema de control de versiones que registra cada cambio de tu código, quién lo hizo y cuándo.

GitHub, por su parte, es la plataforma en línea donde se guardan esos proyectos. Con los dos juntos podés trabajar desde cualquier computadora y colaborar con tu equipo sin pisarse el código.

1. Configurar Git por primera vez

Después de instalar Git, contale quién sos. Estos datos aparecen en cada cambio que guardes:

git config --global user.name "Tu Nombre"
git config --global user.email "tu@correo.com"

2. Los cinco comandos del día a día

git status: ¿qué cambió?

Muestra qué archivos modificaste y cuáles están listos para guardar. Usalo seguido: es tu brújula.

git add: preparar los cambios

Elige qué archivos van a entrar en el próximo guardado. Con un punto agregás todos:

git add index.html
git add .

git commit: guardar una versión

Crea una "foto" del proyecto con un mensaje que explica qué hiciste.

git commit -m "feat: agrega navbar responsive"

Consejo de RollingCode Blog

Escribí mensajes cortos y claros. "Arreglo el footer en celulares" sirve mucho más que "cambios".

git push y git pull: subir y bajar cambios

git push sube tus commits a GitHub y git pull trae los que hicieron tus compañeros. Antes de empezar a trabajar, hacé siempre un pull.

git pull origin main
git push origin main

3. Trabajar en equipo con ramas

Una rama es una copia del proyecto donde podés probar cambios sin tocar la versión principal (main). Cada integrante trabaja en su rama y, cuando está listo, la une a main.

git checkout -b feature/footer
git push origin feature/footer

Resumen rápido

Comando Para qué sirve
git statusVer qué cambió
git addPreparar archivos para guardar
git commitGuardar una versión con un mensaje
git pushSubir los cambios a GitHub
git pullTraer los cambios del equipo

No hace falta memorizar todo de una vez. Con estos cinco comandos ya podés guardar tus proyectos, publicarlos en GitHub y trabajar en equipo.
