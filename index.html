Ruta de aprendizaje

De cero a tu primer proyecto

Un orden sugerido para aprender desarrollo web paso a paso.

01

HTML

La estructura de toda página web: títulos, textos, imágenes, enlaces y formularios.

02

CSS

Colores, tipografías, espacios y diseño. Lo que hace que un sitio se vea profesional.

03

Bootstrap

Grilla y componentes listos para que tus páginas sean responsive desde el primer día.

04

JavaScript

La lógica y la interactividad: el paso que convierte una página en una aplicación.

05

Git y GitHub

Guardar versiones de tu código, trabajar en equipo y mostrar tus proyectos.

06

Back-end y bases de datos

Servidores, APIs y datos: el lado de la aplicación que el usuario no ve.

Preguntas sobre el workshop

¡Hola! Te cuento todo sobre el workshop "¿Los programadores van a desaparecer?". Elegí una pregunta.

¿De qué se trata el workshop?

Hablamos de cómo la IA está cambiando el trabajo de los programadores y de qué habilidades siguen siendo clave.

¿Quiénes son los oradores?

José Díaz, con "Manual de supervivencia del desarrollador", y Tomás Gómez & Pablo Basso, con "De programar línea por línea a construir con IA".

¿Cuándo y a qué hora es?

El jueves 17 de septiembre a las 18 hs.

¿Dónde se hace?

En Gral. Paz 576, entrepiso. También lo podés seguir de forma virtual.

¿Tiene costo?

No, es totalmente gratuito.

¿Es para mí si recién empiezo?

¡Sí! Es para estudiantes, desarrolladores junior, gente de otras áreas con curiosidad y cualquiera que ya use IA para programar.
