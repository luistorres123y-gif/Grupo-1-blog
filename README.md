# RollingCode Blog

Blog educativo sobre programación, desarrollo web y tecnología. El sitio reúne guías para quienes empiezan, artículos sobre herramientas y novedades del ecosistema RollingCode.

## Contenido

- **Primeros pasos:** cómo empezar a programar y crear un portfolio.
- **Front-end:** HTML semántico y diseño adaptable con Bootstrap.
- **Back-end:** conceptos de APIs y desarrollo de servicios.
- **Herramientas:** guías de Git y GitHub.
- **Eventos:** novedades y actividades relacionadas con tecnología.

## Características

- Página principal con publicaciones destacadas y carrusel.
- Páginas por categoría y artículos individuales.
- Secciones de galería, información y contacto.
- Diseño adaptable a celulares, tablets y computadoras.
- Navegación, formularios e interfaz de suscripción.

> Este proyecto es un sitio estático construido con HTML y CSS. Los formularios y las pantallas de acceso son parte de la interfaz; no se asume que tengan un servicio de backend conectado.

## Tecnologías

- HTML5
- CSS3
- [Bootstrap 5.3](https://getbootstrap.com/)
- [Bootstrap Icons](https://icons.getbootstrap.com/)
- Google Fonts (Outfit)

## Cómo verlo localmente

No hace falta instalar dependencias. Cloná el repositorio y abrí `index.html` en un navegador:

```bash
git clone https://github.com/luistorres123y-gif/Grupo-1-blog.git
cd Grupo-1-blog
```

También podés usar la extensión **Live Server** de Visual Studio Code para servir el sitio localmente.

## Estructura principal

- `index.html`: página de inicio.
- `categoria-*.html`: páginas de categorías.
- `post-*.html`: artículos del blog.
- `about.html`, `contact.html`, `gallery.html` y `login.html`: páginas informativas y de interfaz.
- `assets/`: imágenes e íconos.
- `pages/`: estilos y componentes organizados por sección.
- `style.css`: estilos generales.
- `CONTRIBUTING.md`: convenciones de trabajo y colaboración.

## Colaboración

Las contribuciones son bienvenidas. Antes de trabajar en un cambio, consultá [`CONTRIBUTING.md`](CONTRIBUTING.md) para seguir las convenciones del equipo sobre ramas, commits y pull requests.
